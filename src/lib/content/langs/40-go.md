# Go

Go is a small, statically typed, compiled language with a fat standard library, one formatter, and no exceptions. Expect more typing than Python and far fewer surprises at runtime. Snippets target Go 1.25.

## go mod & project layout

Replaces venv + pip + pyproject: one `go.mod` per module, toolchain built in, no environment to activate. `go build` produces a single static binary; cross-compile by setting `GOOS`/`GOARCH`. `gofmt` formats, `go vet` catches suspicious code, `staticcheck` (separate install) catches more.

```sh
go mod init example.com/app
go get github.com/google/uuid@latest
go run .
go build -o app .
go test ./...
gofmt -w . && go vet ./...
GOOS=linux GOARCH=arm64 go build -o app-linux .
```

```text
app/
	go.mod
	main.go          # package main, func main()
	cmd/worker/      # more binaries: go build ./cmd/worker
	internal/db/     # importable only from inside this module
```

## variables, zero values & :=

Every variable starts at its type's zero value, so primitives never need `None`. `:=` declares and infers the type, inside functions only. Unused variables and imports fail the build.

```python
count = 0
name = None
```

```go
var count int      // 0
var name string    // ""
var ok bool        // false
var p *int         // nil (pointers, slices, maps, interfaces, funcs)
x, y := 1, "two"
const Max = 10
```

```go Gotcha
import "os"      // compile error: imported and not used
func main() {
	n := 1       // compile error: declared and not used
	_ = 2        // blank identifier discards a value
}
```

## basic types, conversion & strings

Types: `int`, `int64`, `uint8` (`byte`), `float64`, `bool`, `string`, `rune` (`int32`, one Unicode code point). Conversions are always explicit. A `string` is immutable UTF-8 bytes: `len` counts bytes, `range` yields runes.

```go
n := 3
f := float64(n) / 2           // => 1.5
s := "héllo"
len(s)                        // => 6 (bytes)
len([]rune(s))                // => 5 (runes)
for i, r := range s {         // i = byte offset, r = rune
	fmt.Println(i, string(r))
}
```

```go
v, err := strconv.Atoi("42")  // import "strconv"
strconv.Itoa(v)               // => "42"
strings.Fields(" a  b ")      // => [a b]; import "strings"
strings.Join([]string{"a", "b"}, "-")
fmt.Sprintf("%d %s %q %.2f %v %+v %T", 1, "a", "b", 3.14159, p, p, p)
```

Verbs: `%v` default, `%+v` with field names, `%#v` Go syntax, `%T` type, `%q` quoted, `%x` hex, `%w` wrap error (`Errorf` only).

## slices

A slice is a (pointer, len, cap) view onto an array, roughly a Python list that you must reassign after `append`. `make([]T, len, cap)` preallocates. Slicing `s[a:b]` shares memory with `s`.

```go
s := []int{3, 1, 2}
s = append(s, 4)              // reassign: may reallocate
len(s); cap(s)                // => 4, 6 (cap growth is an implementation detail)
t := s[1:3]                   // => [1 2], shares memory with s
dst := make([]int, len(s))
copy(dst, s)                  // copies min(len(dst), len(s))
slices.Sort(s)                // import "slices"
slices.Contains(s, 3)         // => true
slices.Index(s, 3)            // => 2
```

```go Gotcha
a := []int{1, 2, 3, 4}
b := a[:2]
b = append(b, 99)             // cap(b) is 4, so it writes into a
fmt.Println(a)                // => [1 2 99 4]
c := slices.Clone(a[:2])      // fix: copy first, then append
```

## maps

Like `dict`, but typed. A missing key returns the zero value, so use comma-ok to tell absent from zero. Iteration order is deliberately random. Reading a nil map is fine; writing panics.

```go
m := map[string]int{"a": 1}
v, ok := m["b"]               // => 0, false
m["c"]++                      // missing key starts at 0
delete(m, "a")                // no-op if absent
for k, v := range m {         // random order every run
	fmt.Println(k, v)
}
keys := slices.Sorted(maps.Keys(m))  // import "maps"
```

```go Gotcha
var m map[string]int          // nil map
_ = m["x"]                    // ok: 0
m["x"] = 1                    // panic: assignment to entry in nil map
m = make(map[string]int)      // fix
```

## structs, embedding & composition

No classes, no inheritance. A struct holds data; methods are declared separately. Embedding a struct promotes its fields and methods to the outer type, which looks like inheritance but is composition (no `super`, no polymorphism through the embedded type).

```python
class Animal:
	def __init__(self, name): self.name = name
	def speak(self): return f'{self.name} makes a sound'

class Dog(Animal):
	pass
```

```go
type Animal struct{ Name string }

func (a Animal) Speak() string { return a.Name + " makes a sound" }

type Dog struct {
	Animal        // embedded: fields and methods promoted
	Breed string
}

d := Dog{Animal: Animal{Name: "Rex"}, Breed: "lab"}
d.Speak()         // => "Rex makes a sound"
d.Name            // same as d.Animal.Name
```

## methods & pointer receivers

A method on `T` gets a copy; a method on `*T` can mutate the original. Calling a pointer method on an addressable value works automatically (`c.Inc()` means `(&c).Inc()`).

```go
type Counter struct{ n int }

func (c Counter) Get() int { return c.n }
func (c *Counter) Inc()    { c.n++ }

c := Counter{}
c.Inc()
c.Get()           // => 1
```

```go Gotcha
func (c Counter) Inc() { c.n++ }   // mutates a copy; caller never sees it
```

Use a pointer receiver when the method mutates, the struct is large, or it holds a `sync.Mutex`. If any method needs a pointer, make them all pointers. Only `*T` has the pointer methods in its method set, which matters for interfaces.

## interfaces

Satisfied implicitly: a type implements an interface by having the methods, no `implements` keyword. Think `typing.Protocol`, enforced at compile time. Keep them to one or two methods (`io.Reader`, `fmt.Stringer`), and define them in the consumer's package. `any` is the empty interface (`object`).

```go
type Shape interface{ Area() float64 }

type Rect struct{ W, H float64 }

func (r Rect) Area() float64 { return r.W * r.H }

var s Shape = Rect{2, 3}       // no declaration of intent
s.Area()                       // => 6
r, ok := s.(Rect)              // type assertion, comma-ok form
```

```go
func describe(v any) string {
	switch x := v.(type) {
	case int:
		return "int " + strconv.Itoa(x)
	case fmt.Stringer:         // any type with String() string
		return x.String()
	case nil:
		return "nil"
	default:
		return fmt.Sprintf("%T", x)
	}
}
```

## error handling

Errors are ordinary return values (the `error` interface), not exceptions. Check, add context, return. Wrap with `%w` so callers can inspect with `errors.Is` (match a value) and `errors.As` (match a type).

```go
f, err := os.Open(name)
if err != nil {
	return fmt.Errorf("open config: %w", err)
}
defer f.Close()
```

```go
var ErrNotFound = errors.New("not found")      // sentinel

type ValidationError struct{ Field string }    // custom type

func (e *ValidationError) Error() string { return "invalid " + e.Field }

errors.Is(err, ErrNotFound)                    // walks the %w chain
var ve *ValidationError
if errors.As(err, &ve) {
	fmt.Println(ve.Field)
}
```

`errors.Join(a, b)` combines several errors. Never ignore an `err` silently; if you must, write `_ =` on purpose.

## defer, panic, recover

`defer` runs a call when the surrounding function returns, in LIFO order. It does the job of `with` and `finally`. Arguments are evaluated at the `defer` line. Deferred calls in a loop pile up until the function ends, so wrap the body in a function.

```python
with open(path) as f:
	data = f.read()
```

```go
f, err := os.Open(path)
if err != nil {
	return err
}
defer f.Close()               // runs on every return path
data, err := io.ReadAll(f)
```

`panic` is for programmer bugs (nil deref, index out of range, broken invariants), not for expected failures. `recover` only works inside a deferred function; use it at boundaries like an HTTP server or worker.

```go
func safe(f func()) (err error) {
	defer func() {
		if r := recover(); r != nil {
			err = fmt.Errorf("panic: %v", r)
		}
	}()
	f()
	return nil
}
```

## functions, multiple returns & closures

Functions can return several values (the idiom is `(result, error)`). Results can be named; a bare `return` returns them. Variadic `...T` arrives as a slice; spread with `xs...`. Closures capture variables by reference.

```go
func divmod(a, b int) (q, r int) {
	return a / b, a % b
}

func sum(xs ...int) (total int) {
	for _, x := range xs {
		total += x
	}
	return
}

sum(1, 2, 3)
sum([]int{4, 5}...)
```

Since Go 1.22 each loop iteration has its own variable, so the Python late-binding trap is gone.

```python
fs = [lambda: i for i in range(3)]
[f() for f in fs]    # => [2, 2, 2]
```

```go
var fs []func() int
for i := range 3 {
	fs = append(fs, func() int { return i })
}
fs[0]()    // => 0 (before 1.22: 3)
fs[2]()    // => 2
```

## goroutines & sync.WaitGroup

`go f()` starts a goroutine: a green thread with a tiny stack, scheduled across all CPU cores. There is no GIL, no `async`/`await` coloring, and blocking calls are fine. `main` returning kills every goroutine, so wait explicitly. `wg.Go` (1.25) replaces the `Add`/`Done` boilerplate.

```go
var wg sync.WaitGroup
for i := range 3 {
	wg.Go(func() {         // Go 1.25
		fmt.Println("worker", i)
	})
}
wg.Wait()
```

```go Before 1.25
var wg sync.WaitGroup
for i := range 3 {
	wg.Add(1)
	go func() {
		defer wg.Done()
		fmt.Println("worker", i)
	}()
}
wg.Wait()
```

## channels & select

A channel is a typed, thread-safe queue (`queue.Queue`) that doubles as a synchronization point. Unbuffered: send blocks until a receiver is ready. Buffered: send blocks only when full. Only the sender closes; `range` stops when closed.

```go
jobs := make(chan int, 10)      // buffered; make(chan int) is unbuffered
go func() {
	defer close(jobs)
	for i := range 3 {
		jobs <- i
	}
}()
for j := range jobs {           // ends when jobs is closed
	fmt.Println(j)
}
```

`select` waits on several channels at once (timeouts, cancellation, fan-in). A `done` channel closed by the owner is the classic stop signal.

```go
select {
case v := <-results:
	fmt.Println(v)
case <-time.After(time.Second):
	fmt.Println("timeout")
case <-done:                    // closed by the owner to stop us
	return
}
```

## context

`context.Context` carries cancellation, deadlines, and request-scoped values down a call tree. It is the standard way to stop goroutines and abort I/O, similar to `asyncio` task cancellation but explicit. Pass it as the first parameter named `ctx`; never store it in a struct. Always `defer cancel()`.

```go
ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
defer cancel()
req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
```

```go
func work(ctx context.Context) error {
	select {
	case <-time.After(5 * time.Second):
		return nil
	case <-ctx.Done():
		return ctx.Err()   // context.DeadlineExceeded or context.Canceled
	}
}
```

## sync.Mutex & atomic

Goroutines share memory, so guard shared state with a `Mutex` (like `threading.Lock`) and put it next to the data it protects. Use `atomic` types for single counters and flags. Never copy a struct that contains a mutex. Always run tests with the race detector: `go test -race ./...`.

```go
type SafeCounter struct {
	mu sync.Mutex
	n  map[string]int
}

func (c *SafeCounter) Inc(key string) {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.n[key]++
}
```

```go
var hits atomic.Int64      // import "sync/atomic"
hits.Add(1)
hits.Load()                // => 1
```

## generics

Type parameters go in square brackets after the function name. Constraints are interfaces: `any`, `comparable` (usable with `==` and as map keys), `cmp.Ordered` (supports `<`), or your own union. Callers rarely write the type arguments because inference fills them in. Methods cannot add their own type parameters.

```go
func Map[T, U any](xs []T, f func(T) U) []U {
	out := make([]U, 0, len(xs))
	for _, x := range xs {
		out = append(out, f(x))
	}
	return out
}

Map([]int{1, 2}, strconv.Itoa)    // => [1 2]
```

```go
func Set[K comparable](xs []K) map[K]struct{} { /* ... */ }

func Biggest[T cmp.Ordered](xs []T) T {    // import "cmp"
	return slices.Max(xs)
}

type Number interface{ ~int | ~int64 | ~float64 }   // ~ includes named types
func Sum[T Number](xs []T) (t T) { /* ... */ }
```

## net/http

The standard library is production-grade. Since Go 1.22 `ServeMux` patterns take a method and path wildcards, which removes most of the need for a router library. Handlers get a `ResponseWriter` and a `*Request`.

```go
mux := http.NewServeMux()
mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintf(w, "user %s", r.PathValue("id"))
})
log.Fatal(http.ListenAndServe(":8137", mux))
```

```go
client := &http.Client{Timeout: 5 * time.Second}
resp, err := client.Get("https://example.com")
if err != nil {
	return err
}
defer resp.Body.Close()
body, err := io.ReadAll(resp.Body)
```

`http.Get` uses a client with no timeout; always build your own. A 404 or 500 is not an `err`: check `resp.StatusCode`.

## encoding/json

Struct tags control field names. Only exported (capitalized) fields are serialized. `omitempty` drops zero values, and `omitzero` (1.24) drops zero-valued structs such as `time.Time`. Unmarshal into a typed struct when you know the shape; use `map[string]any` when you don't.

```go
type User struct {
	ID    int    `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email,omitempty"`
}

b, err := json.Marshal(User{ID: 1, Name: "Ada"})
// => {"id":1,"name":"Ada"}
var u User
err = json.Unmarshal(b, &u)       // pass a pointer
```

```go
var m map[string]any
err := json.Unmarshal(data, &m)
age := m["age"].(float64)         // JSON numbers decode as float64
dec := json.NewDecoder(r.Body)    // streaming; reads from an io.Reader
dec.DisallowUnknownFields()
```

## testing

Tests live next to the code in `*_test.go`, functions named `TestXxx(t *testing.T)`. No assertion library: compare and call `t.Errorf`. The idiom is a table of cases run through `t.Run`.

```go
func TestAdd(t *testing.T) {
	tests := []struct {
		name       string
		a, b, want int
	}{
		{"pos", 1, 2, 3},
		{"neg", -1, -2, -3},
	}
	for _, tc := range tests {
		t.Run(tc.name, func(t *testing.T) {
			if got := Add(tc.a, tc.b); got != tc.want {
				t.Errorf("Add(%d, %d) = %d, want %d", tc.a, tc.b, got, tc.want)
			}
		})
	}
}
```

```sh
go test ./...
go test -run 'TestAdd/pos' -v
go test -bench . -benchmem
go test -race -cover ./...
```

A benchmark is `func BenchmarkAdd(b *testing.B) { for b.Loop() { Add(1, 2) } }`. `testing/synctest` (stable in 1.25) runs concurrent code in a bubble with a fake clock, so tests of timeouts and tickers finish instantly and deterministically.

## tooling & idioms

- `gofmt` is law: no style debates, your editor runs it on save (`goimports` also fixes imports).
- Errors are values: handle them where you can act, wrap them where you cannot.
- Accept interfaces, return concrete structs.
- Make the zero value useful (`var buf bytes.Buffer`, `var mu sync.Mutex` work unconfigured).
- Short names in small scopes (`i`, `r`, `ctx`); package names are short and lowercase, so `http.Client`, not `http.HTTPClient`.
- "Don't communicate by sharing memory; share memory by communicating", but a mutex is fine when simpler.
- `go vet ./...` and `staticcheck ./...` before committing.
- Docs offline: `go doc strings.Builder`, `go doc -all net/http`. Read [Effective Go](https://go.dev/doc/effective_go).
